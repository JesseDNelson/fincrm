# FinCRM

A customer relationship management application for a fictional
US-based financial institution.

This project demonstrates secure authentication, role-based access
controls, customer management, and audit logging.

## Tech Stack

- Frontend: React + TypeScript + Vite
- Backend: Node.js + Express + TypeScript
- Database: SQLite (planned)

## Project Structure

- `client/` - React frontend
- `server/` - Express REST API
- `docs/` - Architecture and audit documentation

## Development Setup

### Frontend

cd client
npm install
npm run dev

### Backend

cd server
npm install
npm run dev
